# Security

## Supported versions

Only the latest release receives security fixes.

## Reporting

Send reports to hi@mumd.dev. Include the version, the operating system, and a
short reproduction. Please do not open a public issue before a fix is ready.

## Scope

The browser isolates each tab in its own in memory session. Reports about
fingerprint leaks between tabs, proxy authentication, request interception, or
the extension loader are in scope.
